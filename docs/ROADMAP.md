# Roadmap

SearchProbe is focused on making Google Search Console a reliable local primitive
for developers, scripts, and coding agents.

## Available now

- Guided Google OAuth setup using a user-owned Desktop client.
- Read-only property discovery and Search Analytics queries.
- Deterministic period comparison.
- Single and batch indexed URL inspection.
- Read-only sitemap listing and inspection.
- Stable JSON output with explicit metadata and structured errors.
- A local stdio MCP server exposing all read-only SearchProbe operations.
- Personal SearchProbe skills for Claude Code and Codex.
- Prebuilt macOS and Linux releases for arm64 and amd64.

## Current focus

- Installation polish across supported platforms.
- Smoother Google OAuth onboarding.
- Reliable Claude Code and Codex integration.
- Clearer diagnostics and recovery instructions.
- JSON compatibility guidance and documentation.

## Considering

- Multi-account and profile ergonomics.
- Broader distribution, including Homebrew.
- Additional convenience queries where they make common workflows meaningfully simpler.

Roadmap items are possible directions, not commitments. SearchProbe will remain a
useful read-only CLI independent of optional integrations.
